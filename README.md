# 📅 課表安排 Course Scheduler

學生個人用的週課表排課工具。手動新增課程、點選放進課表，**同一時段排到兩門以上會自動標紅提示衝突**。純前端、資料存在瀏覽器，不需登入。

## 功能

- 一週 ×（07:00–21:00）格狀課表，採學校節次制
- 自訂課程（名稱／老師／教室／顏色），一門課可有多個上課時段、可連堂
- 右側課程清單：勾選即放上課表、取消即收回（方便比較不同選課組合）
- **衝突偵測**：同一格只有一門課顯示綠色、兩門以上變紅色，頂端顯示總衝突數
- 滑過課程時，課表上同一門課的所有格子一起高亮
- 底部摘要：已排門數、總節數、是否有早八、最忙的一天
- 資料自動存進瀏覽器 localStorage

## 技術

React 19 · TypeScript · Vite · Tailwind CSS v4 · Zustand（含 localStorage 持久化）

## 開發

```bash
npm install
npm run dev        # 本地開發
npm run build      # 打包到 dist/
npm run typecheck  # TypeScript 型別檢查
```

## 部署

推到 `main` 分支會由 GitHub Actions 自動打包並部署到 GitHub Pages
（設定見 `.github/workflows/deploy.yml`）。
